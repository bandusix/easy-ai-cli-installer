Built for developers who ship

⚡︎

Zero Config

No npm install. No PATH exports. No version conflicts. Just download, double-click, and all CLIs are ready in your terminal.

🔒

100% Offline

Bundled mode packs Node.js runtime + every CLI tarball + binaries into a single executable. Install on air-gapped machines, no network required.

🔄

Auto-Update

Latest mode fetches newest releases from npm and GitHub at install time. Or use the bundled payload — rebuilt daily by CI.

🎯

Claude API Relay

Fill in your custom Base URL + Token in the GUI. Only affects the claude command, leaves other CLIs and system env untouched.

🌐

Trilingual UI

English, Simplified Chinese, Traditional Chinese. Auto-detects your system locale, with a manual switcher in the top-right corner.

🚀

Daily CI Builds

GitHub Actions checks npm and GitHub Releases every 24 hours. New CLI version? Installer rebuilds, repacks, and publishes automatically.
